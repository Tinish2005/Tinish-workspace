# 🚀 Tinish Workspace

A desktop-style AI portfolio built using React, Vite, Framer Motion, and Google Gemini.

Tinish Workspace transforms a traditional portfolio into an interactive desktop experience where visitors can explore projects, skills, experience, and interact with an AI-powered personal assistant.

# 🚀 Local Setup

Clone the repository:

```bash
git clone https://github.com/Tinish2005/Tinish-workspace.git
```

Navigate to frontend:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Create `.env`

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```
